# Голос Рины

- **Файл:** `rina-voice-v1.wav` — 3.20 с, 48 кГц
- **sha256:** `8d16b59e9424a4a944b3b8ff6202b230c9397e9da7775a5f9a1c580eb059f7e8`
- **Выбран:** 22 сентября 2026
- **Задача плана:** `V-03`; решение — [ADR 0003](../../docs/adr/0003-voice-identity.md)

## Что это за файл

**Это и есть голос, а не пример голоса.** ADR 0003 требует, чтобы личность Рины хранилась как собственность проекта — экспортированной, версионируемой, наравне с эмблемой. Здесь она и хранится: всё, что Рина говорит, синтезируется с этой записи как с образца.

Человека, который её произносит, не существует. Голос создан словесным описанием, без единой чужой записи, и это проверено замером — см. ниже.

## Как он получен

Модель `openbmb/VoxCPM2` (Apache-2.0), пакет `voxcpm` 2.0.3, `torch` 2.14.0+cpu.

```python
torch.manual_seed(20260923)
wav = model.generate(
    text="(A young woman, soft gentle voice, slightly high pitch, "
         "calm even pace)Привет. Я Рина, и это мой собственный голос.",
    cfg_value=2.0,
    inference_timesteps=10,
)
```

Сид задаётся глобально: параметра `seed` у `generate()` в этой версии нет. Тот же сид возвращает **побайтно** тот же файл — проверено, косинус 1.000. Другой сид даёт другого человека (0.270).

Рецепт записан не для того, чтобы файл можно было не хранить, а наоборот: файл — канонический, рецепт лишь объясняет, откуда он. Смена версии модели рецепт обесценит, файл — нет.

## Как им пользоваться

Образец подаётся вместе со своей расшифровкой:

```python
wav = model.generate(
    text="<что сказать>",
    prompt_wav_path="assets/voice/rina-voice-v1.wav",
    prompt_text="Привет. Я Рина, и это мой собственный голос.",
    cfg_value=2.0, inference_timesteps=10,
)
```

**Не задавайте голос описанием каждый раз.** Одно описание не удерживает тембр: соседние реплики расходятся на 0.258 при том, что два случайных чужих человека расходятся на 0.308. С образцом — 0.716 при уровне «тот же человек» 0.856.

## Чем это проверено

Замеры — [`tools/voice_identity.py`](../../tools/voice_identity.py), сеть верификации диктора CAM++ (3D-Speaker). Шкала на контрольной выборке из восьми живых дикторов: разные люди — до 0.537, тот же человек — около 0.856.

| | |
|---|---|
| до ближайшего из восьми живых дикторов | **0.278** максимум |
| тембр между репликами | 0.675…0.901, среднее 0.758 |
| английская фраза против образца | 0.818 |
| английская против русских | 0.790 |

Первая строка — условие ADR 0003: голос дальше от каждого живого человека, чем эти люди друг от друга. Вторая — честный зазор: тембр гуляет больше, чем у живого человека между записями.

Два языка работают одним голосом. «Готово. Открываю Visual Studio Code» и «Запускаю Google Chrome и Telegram» расшифровываются дословно: названия произносятся по-английски, а не транслитерируются. Целиком английская фраза держит тембр не хуже, чем русские держат его между собой.

## Чего здесь нет

Рабочего конвейера. Синтез на процессоре идёт с RTF около 19 — три секунды речи за минуту, — так что до включения в продукт нужна видеокарта либо другой способ. Выбор движка и вопрос «стриминг против выразительности» — `V-04`.
