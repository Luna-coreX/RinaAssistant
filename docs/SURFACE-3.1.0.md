# Инвентаризация поверхности 3.1.0

- **Задача плана:** `4.0-A06`
- **Дата:** 1 сентября 2026
- **Источник:** обход дерева виджетов, а не чтение файлов. Каждый экран построен и разобран программно — сначала пустым, затем с данными, потому что карточки команд, напоминаний, истории и плагинов на пустом экране не существуют. Переключатели считались отдельно: `ToggleSwitch` — не наследник `QAbstractButton`, и обычный обход его не видит.

## Зачем это

[`INVENTORY-3.1.0.md`](INVENTORY-3.1.0.md) описывает поведение, и его стережёт golden-набор. У интерфейса такого набора нет и не будет: после редизайна всё отличается намеренно, и автоматически отличить «так задумано» от «потеряли» нечем.

Роль критерия играет сверка `4.0-R11`: **каждая строка этого документа обязана найти место в новом интерфейсе, и в новом интерфейсе не должно быть ничего, чего нет здесь** — иначе это протащенная возможность, запрещённая правилом рубежа.

Главный раздел — [§3, «Доступно только отсюда»](#3-доступно-только-отсюда). Именно эти действия редизайн теряет молча: они существуют как одна кнопка в одном месте, и если её не перенести, возможность исчезнет, а поведение ядра останется прежним, и golden-набор ничего не заметит.

## 1. Навигация

Восемь вкладок в боковой панели, в порядке появления:

| № | Вкладка | Значок |
|---|---|---|
| 1 | Рина | 🌸 |
| 2 | Команды | ⚡ |
| 3 | Напоминания | ⏰ |
| 4 | Горячие клавиши | ⌨️ |
| 5 | История | 🕑 |
| 6 | Настройки | ⚙️ |
| 7 | О программе | ℹ️ |
| 8 | Плагины | 🧩 |

⚠ **Странность:** «Плагины» стоят после «О программе». Раздел о продукте разрывает рабочие вкладки и служебные. Порядок в новой информационной архитектуре (`4.0-R04`) решается заново, но потеряться вкладка не должна.

Каждый включённый плагин со своей страницей добавляет вкладку сверх этих восьми.

**Заголовок окна:** свернуть, развернуть, закрыть. Окно без системной рамки, поэтому это единственный способ управлять им мышью.

**Трей:** «Открыть Рину», строка состояния «● Rina Online» (неактивная), разделитель, «Выход».

**Строка команд** внизу окна: поле «Введите команду, напр. «запусти калькулятор» и нажмите Enter…» и кнопка «Отправить».

**Плавающая строка команд** — то же поле поверх всех окон, включается настройкой или хоткеем.

## 2. Экраны и элементы

### Рина

| Раздел | Элемент | Тип |
|---|---|---|
| Голос и речь | Система синтеза | список: без озвучки, pyttsx3, Edge Neural, Google TTS, Piper |
| | Распознавание речи | список: выключено, Google, Vosk, Whisper, PocketSphinx |
| | Голос | список голосов выбранного синтеза |
| | Слова активации | поле, через запятую |
| | Громкость | ползунок 0..100, значение подписью |
| | Скорость речи | ползунок 50..200, значение подписью («1.0x») |
| | Проверка голоса | кнопка «Проверить» + строка результата |
| Поведение | Отвечать голосом | переключатель |
| | Всегда слушать | переключатель |

**Состояния:** список голосов пуст → «— нет голоса —»; движок не установлен → в списке помечен «(недоступен)»; проверка голоса не удалась → «Ошибка озвучки: …».

### Команды

| Элемент | Тип |
|---|---|
| Экспорт, Импорт | кнопки |
| Новая команда | кнопка → диалог конструктора |
| Поиск команды… | поле фильтра |
| Список своих команд | карточка: имя, «Тип · цель», переключатель включения, «Выполнить», «Изменить», «Удалить» |
| Встроенные команды | справочный список 11 примеров |
| Найденные программы | кнопка обновления индекса + счётчик |

**Состояния:** нет своих команд → «У вас пока нет своих команд»; идёт сканирование → кнопка «Ищу…» выключена; экспорт при пустом списке → «Нечего экспортировать»; ошибка записи → «Не удалось сохранить: …»; успех → «Экспортировано команд: N» / отчёт об импорте.

### Напоминания

| Элемент | Тип |
|---|---|
| Отменить все | кнопка; рядом счётчик «активных: N» |
| О чём напомнить | поле, необязательное |
| Через сколько | поле числа + список единиц (минут, секунд, часов) |
| Поставить | кнопка |
| Список запланированного | карточка: «Таймер: текст», время срабатывания и остаток («21:03 · осталось 9 мин 59 с»), «Отменить» |

**Состояние:** пусто → «Ничего не запланировано».

### Горячие клавиши

| Раздел | Элемент |
|---|---|
| Основная клавиша | «Активация ассистента» — поле захвата комбинации |
| Дополнительные действия | шесть полей захвата: слушать, режим «всегда слушать», показать/скрыть окно, вкл/выкл озвучку, фокус на строку команд, плавающая строка |

**Состояния:** не задано → «— не задано —»; глобальный перехват недоступен (не установлен pynput) → предупреждение о том, что комбинации работают только при активном окне.

### История

| Элемент | Тип |
|---|---|
| Экспорт | кнопка (JSON или текст); рядом счётчик «N записей» |
| Очистить | кнопка |
| Поиск по истории… | поле фильтра |
| Лента | реплики по дням («Сегодня»); у каждой — автор, источник, время. Действий у записи нет |

**Состояние:** пусто → «История пуста».

### Плагины

| Элемент | Тип |
|---|---|
| Установить из папки, Установить из архива | кнопки |
| Обновить | кнопка перечитывания каталога |
| Список плагинов | карточка: значок, имя, версия, автор, описание, состояние («Включён»/«Выключен»), метки «вкладка» и «настройки», переключатель |
| Путь | строка «Папка плагинов: …» |

**Состояния:** ничего не найдено → «Плагины не найдены»; битый манифест → карточка с текстом ошибки, переключатель выключен; ошибка установки → «Не удалось установить: …»; замена существующего → сообщение о замене и о том, что плагин выключен.

### Настройки

Девять разделов.

| Раздел | Элементы |
|---|---|
| Внешний вид | тема (5), акцентный цвет (6), язык (5) |
| Аудио | микрофон, динамик, «Проверить» микрофон |
| Модели голоса | модель Whisper (tiny/base/small/medium); чувствительность активации 50..98; длительность записи 3..20 с; модель Vosk (поле + «Обзор…»); модель Piper («Проверить модели») |
| Программы | «Добавить папку…», «Обновить список», «Забыть все», список добавленных папок |
| Поведение приложения | запуск с системой, сворачивать в трей, запускать свёрнутым, плавающая строка, уведомления, звуковые эффекты, проверять обновления + «Проверить сейчас» |
| Ответы моделью (ИИ) | отвечать моделью; адрес Ollama; выбор модели; «Проверить связь»; характер |
| Поиск в интернете | поисковая система (4); искать нераспознанное |
| Приватность | сохранять историю |
| Диагностика | подробность журнала; записывать тексты реплик; «Открыть папку»; «Сбросить настройки» |

**Состояния:** модель не выбрана → «не выбрано»; проверка связи не удалась → «Ошибка проверки: …»; проверка микрофона не удалась → «Не удалось проверить микрофон.»; адрес модели не локальный → предупреждение рядом с полем.

### О программе

Версия и сборка; ссылки «Веб-сайт», «Исходный код», «Сообщить об ошибке»; список технологий; благодарности; строка лицензии.

### Страница плагина

Включённый плагин может добавить вкладку. Её содержимое описывается плагином декларативно (`title`, `text`, `note`, `items`, `button`, `input`, `table`, `progress`, `badge`, `divider`), поэтому набор элементов заранее неизвестен — известен только словарь, которым он выражается.

**Состояние:** у встроенного плагина заметок пусто → «Пока пусто. Скажите: «запиши купить молоко»».

### Диалоги

**Конструктор команды:** тип (6 вариантов), поле цели по типу (программа с автодополнением и «Обзор…», папка, сайт, текст для озвучки, системное действие из списка, конструктор шагов с «Добавить шаг»), фразы активации, режим совпадения, ответ ассистента, «Отмена» и «Сохранить».

**Первый запуск:** тема, акцентный цвет, обращение к ассистенту, отвечать голосом, «Пропустить» и «Начать».

**Обновление доступно:** версия, описание, переход к загрузке, отложить.

**Программа не найдена:** предложение указать файл вручную. Показывается **только если окно на экране** — иначе диалог выпрыгнул бы поверх чужой полноэкранной работы.

## 3. Доступно только отсюда

Ядро этого документа. У каждого действия — единственная точка входа, голосом его выполнить нельзя.

| Действие | Адрес | Что будет, если потерять |
|---|---|---|
| Экспорт команд | Команды → «Экспорт» | Нет способа перенести команды на другую машину |
| Импорт команд | Команды → «Импорт» | То же в обратную сторону |
| Создать, изменить, удалить команду | Команды → карточка / «Новая команда» | Пользовательские команды становятся нередактируемыми |
| Включить или выключить команду | Команды → переключатель на карточке | Нельзя временно отключить, только удалить |
| Экспорт истории | История → «Экспорт» | Разговор нельзя вынести из программы |
| Очистить историю | История → «Очистить» | Приватность: нельзя стереть сказанное |
| Установить плагин из папки или архива | Плагины → две кнопки | Плагины можно только удалять руками из каталога |
| Включить или выключить плагин | Плагины → переключатель на карточке | — |
| Настройки плагина | Плагины → карточка | — |
| Проверить голос | Рина → «Проверить» | Нельзя убедиться, что синтез работает, до первой команды |
| Проверить микрофон | Настройки → «Проверить» | Нельзя отличить «не слышит» от «не поняла» |
| Проверить связь с моделью | Настройки → «Проверить связь» | Непонятно, почему модель молчит |
| Проверить модели Piper | Настройки → «Проверить модели» | — |
| Выбрать модель Vosk | Настройки → «Обзор…» | Vosk невозможно включить |
| Добавить папку с программами | Настройки → «Добавить папку…» | **Portable-программы перестают поддерживаться** |
| Обновить список программ | Настройки → «Обновить список», Команды → кнопка обновления | Новая программа не появится сутки (время жизни кэша) |
| Забыть выученные соответствия | Настройки → «Забыть все» | Ошибочно выученный алиас не отменить |
| Открыть папку журналов | Настройки → «Открыть папку» | Журнал нечем приложить к сообщению об ошибке |
| Сбросить настройки | Настройки → «Сбросить настройки» | — |
| Проверить обновления сейчас | Настройки → «Проверить сейчас» | Только автоматическая проверка при запуске |
| Назначить любую из семи комбинаций | Горячие клавиши | Хоткеи становятся неизменяемыми |
| Все настройки без исключения | Настройки, Рина | Голосом ни одна настройка не меняется |
| Свернуть, развернуть, закрыть окно | Заголовок окна | Окно без системной рамки — других способов нет |

**Доступно и голосом тоже** (то есть потеря кнопки не отрезает возможность): отменить все напоминания, поставить напоминание, снимок экрана, громкость и медиа, запуск программ.

## 4. Состояния, которые надо спроектировать заново

Собраны из всех экранов. Экран без этих состояний — половина экрана (`4.0-R06`).

| Состояние | Где встречается |
|---|---|
| Пусто | команды, напоминания, история, плагины, голоса, список моделей |
| Идёт работа | сканирование программ («Ищу…», кнопка выключена), проверка голоса, проверка микрофона, проверка связи, ответ модели |
| Ошибка операции | экспорт, импорт, установка плагина, проверка голоса, проверка микрофона, проверка связи |
| Недоступно | движок распознавания не установлен («(недоступен)»), глобальные хоткеи без pynput, битый плагин |
| Не выбрано | модель Vosk, модель Piper, модель Ollama, голос |
| Предупреждение | нелокальный адрес модели, замена плагина, включённая запись текстов реплик |
| Много элементов | история за месяцы, длинный список найденных программ, много команд |
| Длинный текст | реплика модели на несколько абзацев, длинный путь к программе |

**Отдельно для 4.0:** состояния «ядро недоступно» и «ядро перезапускается» в 3.1.0 не существует — ядро в том же процессе. В новой оболочке их придётся придумать с нуля (`4.0-F12`).

## 5. Как этим пользоваться при сверке

`4.0-R11` считается закрытым, когда:

1. Каждая строка §3 имеет адрес в новом интерфейсе. Не «примерно то же» — конкретный экран и элемент.
2. Каждое состояние из §4 нарисовано для каждого экрана, где оно возможно.
3. В новом интерфейсе нет действия, которого нет в §2 или §3. Если появилось — это новая возможность, и она нарушает правило рубежа 4.0-port.

Странности, помеченные ⚠, решаются отдельно: порядок вкладок в новой информационной архитектуре можно менять, но это решение, а не побочный эффект переноса.
