# Страница продукта

Задача плана [`4.0b-D01`](../docs/ROADMAP.md). Четыре страницы, написанные
руками, — продукт и документация API, каждая по-русски и по-английски, —
плюс одиннадцать порождённых: документы репозитория, включая полный план.
Оформление, значения из дизайн-системы, шрифты и знак.

## Мир

**Коммутационное поле.** Просверленная плита, шнур сигнального цвета,
ламповый индикатор занятой линии, инвертированная наборная этикетка.
Фраза соединяется с действием, и соединение видно: в первом экране шнур
прокладывается от гнезда «сказано» к гнезду «сделано» и зажигает лампу.

Мир выбран жребием скилла Impeccable из семи выведенных кандидатов (seed
`a2a26a10`, кандидат 4) и поднят четырьмя отклонёнными челленджерами;
контракт направления записан комментарием в начале `<body>` каждой
страницы и проверяется — страница, потерявшая его, дальше не сверяется ни
с чем.

**Это не интерфейс программы.** Программа — плоская лицевая панель
прибора; страница — поле соединений. Общего у них фирменные цвета, три
гарнитуры и штриховка необратимого; всё остальное решено заново.

## Как это устроено

| Файл | Кто его пишет |
|---|---|
| `index.html`, `en/index.html` | человек; разделы у обеих одни и те же |
| `api/index.html`, `en/api/index.html` | человек; то же правило |
| `style.css` | человек; ни одного цвета числом — только `var(--…)` |
| `tokens.css` | **порождается** `tools/gen_site.py` по `docs/design/tokens.json` |
| `wires.svg` | **порождается** им же: жгут под страницей, цвет из тех же значений |
| `docs/*/index.html` | **порождаются** им же из `.md` дерева — одиннадцать документов |
| `fonts/`, `logo.png`, `favicon.ico` | **копируются** тем же порождателем |
| `_headers` | политика ответов Cloudflare Pages |

Копии здесь не от хорошей жизни: хостинг отдаёт одну папку и ничего выше
неё, поэтому страница не может смотреть в `assets/`. Копия, которая может
разойтись с источником, — это тот же снимок несуществующей программы, что
уже случался в README; поэтому `gen_site.py --check` сверяет каждый
скопированный файл побайтово.

## Документы страницами

Одиннадцать документов дерева публикуются как `/docs/<имя>/`: README,
архитектура, руководство по плагинам, дизайн-система, безопасность,
модель угроз, отладка, участие, разбор входящего, список изменений и
полный план. Страницы **порождаются** из тех же `.md` — руками их не
пишут, и разойтись с деревом они не могут: `gen_site.py --check`
сверяет каждую с заново собранной.

Разбирает Markdown свой `tools/markdown_site.py` — подмножество, и
выбранное: сначала посчитали, чем документы пользуются на самом деле.
Ссылки переписываются: документ, у которого есть страница, становится
местным адресом, остальное уходит в хранилище. Ссылка, молча ставшая
404, — обычный способ, которым эта затея перестаёт работать, поэтому
`check_site.py` проверяет каждую.

Полный план сворачивает объяснение каждой задачи в `details`: четыре
тысячи строк подряд не читаются, список задач с состоянием — читается.
Полоса сверху считает сделанное по рубежам, а рубеж задачи берёт из
`docs/scope-4.0.json`, а не из заголовка, под которым она стоит.

**Языки не выравниваются.** Семь документов написаны по-русски, четыре
по-английски; на обеих страницах продукта тот, чей язык не совпадает с
языком страницы, помечен. Перевести их — отдельная работа, а подпись
по-русски над английским текстом была бы хуже честной пометки.

## Макет программы

`/mock/` — окно Рины, по которому можно ходить. **Это единственная
страница сайта со скриптом**, и обещание из-за неё сузилось: раньше
«страница не выполняет скриптов» относилось ко всему сайту, теперь — ко
всему, кроме этого адреса. Сузить обещание можно; сузить молча нельзя,
поэтому страница говорит об этом первой строкой, `_headers` выдаёт
`script-src 'self'` **только** разделу `/mock/*`, а `check_site.py`
следит и за тем и за другим: скрипт есть ровно здесь, он свой, и
разрешение не расползлось на `/*`.

Отвечает макет не выдумкой. Фразы и разбор порождены из
`docs/golden/utterances.json` — того же набора, которым закреплён
настоящий разбор, — все 134 случая, без правок. Своими у макета
остаются только слова ответа: набор закрепляет, что она поняла, а не
какими словами отвечает, и это на странице сказано.

Одна и та же фраза записана в наборе по нескольку раз: «выключи
компьютер» без слова активации — молчание, а не выключение. Первая
редакция искала по фразе и молча брала последнее прочтение; теперь
макет показывает все и приводит пояснение набора.

Три отделки — из `finishes.css`, порождённого из тех же `tokens.json`;
серебро выходит светлым, как ему и следует. Контраст каждой из трёх
проверяется отдельно. Состояние фигуры написано словом: кольцо набрано
цветом фаски и даёт против плиты около 2.5 — меньше, чем должна
значимая графика, и красить его ярче значило бы сделать покоящееся окно
громким.

**Снимков экрана здесь нет.** Те, что стояли, показывали интерфейс двух
выпусков назад; на их место придёт работающий макет программы, а пока
разделы описаны набором. `check_site.py` следит, чтобы снимок не
вернулся в страницу молча.

Обновить после правки токенов или шрифтов:

```
python tools/gen_site.py
```

## Движение

Поставленное движение одно: коммутация в первом экране — шнур
прокладывается, надпись садится на место, лампа занимает линию и гаснет до
ровного свечения.

Под всей страницей — изнанка панели. Первой попыткой была та же сетка
гнёзд, растянутая на всю страницу: она оказалась фоном из точек, какой
стоит у каждого тёмного лендинга, и двигалась на один свой шаг за
полторы минуты, то есть не двигалась. Теперь там жгут: шесть кривых во
всю высоту волосяной линией (на узком экране четыре), по трём из них
изредка проходит сигнал, и поверх идёт свет по плите раз в сорок
секунд. Сигнальный цвет сюда не спускается — акцент на странице один.

Жгут едет целиком, `transform` на самом `svg`, поэтому идёт в
компоновщике. Провод и сигнал пересекают строки, набранные мягкими
чернилами, поэтому обе пары меряются на контраст, а силу слоя проверка
читает прямо из `style.css`: 5.81 и 4.72 при нужных 4.5. В полную силу
сигнал давал бы 2.39 — то самое число, из-за которого мягких чернил нет
над полем гнёзд.

Остальное привязано к прокрутке, а не к часам: шнур под верхней рейкой
длиной в пройденный путь, прочерк линии у строки события, приход и уход
блоков (`come-and-go`), выкатывание показаний наборной этикетки. Всё это
на прокруточных временных шкалах CSS, под `@supports (animation-timeline:
view())`: в браузере без них правила не применяются целиком, и страница
остаётся просто видимой.

**Скриптов нет вовсе.** Всё движение — CSS; `prefers-reduced-motion`
выключает его целиком. Содержимое видно и без анимации: ни одно правило
вне `@supports` не гасит содержимое, и это проверяется.

## Что проверяется

`python tools/check_site.py` — отдельная проверка, входит в общий набор
(`tools/regress.py`). Она сверяет:

* **числа** на странице продукта с кодом: системные действия, виды шага,
  плагины, языки, записанные фразы, число проверок в наборе;
* **документацию API с самим API, в обе стороны**: хуки, поля класса,
  службы контекста, поля манифеста и инструмента, виды элемента страницы
  и настройки, каталог разрешений с отметкой «плагину не выдаётся», числа
  из контракта протокола. Хук, добавленный в код и не описанный, красит
  проверку так же, как хук, исчезнувший из кода;
* **версию** с версией оболочки;
* **разделы** русской и английской страниц — набор и порядок, отдельно у
  продукта и у документации: расходятся двуязычные страницы молча;
* **ссылки внутрь** — файл существует; **ссылки в хранилище** — документ
  на месте в дереве; **якоря** — раздел с таким именем есть;
* **чужие узлы** — их нет: ни скрипта, ни счётчика, ни шрифта со
  стороннего сервиса;
* **обещания** — про деньги (`4.0b-C07`) и про телеметрию сказаны на обеих
  страницах продукта;
* **цвет числом** в `style.css` — запрещён;
* **папка не исключена** из хранилища.

## Публикация

Cloudflare Pages, без сборки:

* **Build command** — пусто;
* **Build output directory** — `site`;
* **Root directory** — корень хранилища.

Ни `node`, ни `python` на стороне хостинга не нужны: в папке лежит ровно
то, что отдаётся. Посмотреть локально:

```
python -m http.server 8765 --directory site
```

Домен и подключение хранилища делаются в панели Cloudflare — это
единственный шаг, которого нет в коде.

## Чего на странице нет

Скриптов. Счётчиков. Cookie. Обращений к чужим узлам — шрифты и знак
лежат здесь же. Снимков экрана. Светлого исполнения: мир — сумрачная коммутаторная с
горящими лампами, и светлая копия погасила бы их. Переключателя тем тоже
нет — его не сделать без скрипта, а скрипт противоречил бы всему
вышесказанному.
