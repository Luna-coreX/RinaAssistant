# Плагины Rina

В этой папке — интерфейс плагинов (`api.py`, `page_spec.py`, `settings_spec.py`), их менеджер и процесс плагина (`host.py`), а также плагины, которые поставляются вместе с программой.

Плагин — папка с двумя файлами: `plugin.json` и `main.py`. Текущая версия API — 4; плагины версий 1–3 не загружаются.

- Руководство: [`docs/plugins/WRITING-PLUGINS.md`](../docs/plugins/WRITING-PLUGINS.md).
- Схема вкладки плагина: [`docs/plugins/PAGE-SCHEMA-v2.md`](../docs/plugins/PAGE-SCHEMA-v2.md).
- Примеры для разработчиков: [`examples/plugins/`](../examples/plugins/). В установщик они не входят.

Плагин запускается в отдельном процессе тем же интерпретатором и с теми же правами, что и программа. Отдельный процесс защищает Рину от зависшего или упавшего плагина, но не ограничивает его код: устанавливайте плагины только из источников, которым доверяете.
