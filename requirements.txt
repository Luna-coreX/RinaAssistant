# (`tools/build_release.py` reads this file). One list, so the environment a
# developer runs and the one a person gets cannot drift apart.

# - the shell (.NET) — it draws the window; the core runs headless, no Qt;
# - the optional engines — Vosk, Piper, Whisper models: the first-run wizard
#   installs the ones a person picks;
# - the 3.1.0 application's list — `archive/3.1.0-app/requirements.txt`.
#
# The packages these pull in are not pinned yet; a full lock with hashes is
# planned for 4.0.0 Stable.
